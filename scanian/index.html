How saving works

Anyone can read this page. Connect editing to change it. Finish editing saves your meanings to GitHub. Rule and question buttons also save to GitHub. The save history keeps earlier versions.

New changes can take a short time to appear on the public page. A browser draft is a backup until GitHub confirms the save.

Connect editing

Use a GitHub token for this website only.

  1. Create a fine-grained token on GitHub.
  2. Choose owner PenghaoWang1225. Choose only bridge under repository access.
  3. Set Contents to Read and write. Set an expiry date. Create the token.
  4. Paste the token here. Do not send it in chat.
